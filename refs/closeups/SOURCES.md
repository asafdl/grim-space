# Real prominence close-ups (public domain)

These are the reference frames for the close-up shot in the sun test clip.  The
shader's prominence material is judged against them: thin threads flowing along
the loop, layered ribs, a bright core inside a soft envelope, and turbulence
inside the loop rather than a solid tube.
